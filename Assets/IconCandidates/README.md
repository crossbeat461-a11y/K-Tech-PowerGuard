# K-Tech PowerGuard — アイコン候補

K-Tech Studio の俚語 **{K+}** と **バッテリー** をモチーフにした Mac アプリアイコン案（3種）。

| 案 | ファイル | コンセプト |
|----|----------|------------|
| **A** | `powerguard-icon-candidate-1-kplus-in-battery.png` | シルバー Neo 系。電池シルエット内に **{K+}** をそのまま配置。シンプルでメニューバーでも判別しやすい |
| **B** | `powerguard-icon-candidate-2-kplus-charge.png` | インディゴ系。**K+ 充電**と 80% 付近の残量イメージ。PowerGuard の「上限 80%」と相性がよい |
| **C** | `powerguard-icon-candidate-3-badge-shield.png` | ブラッシュ系。**{K+}** バッジ + 盾（Guard）のニュアンス。やわらかい K-Tech Studio 向け |
| **採用案（1×2）** | `powerguard-icon-candidate-1-layout-2-style.png` | **案Aの構図**（電池内 **{K+}**）+ **案Bのトーン**（インディゴグラデ・80%残量・充電ハイライト） |

## 次のステップ

1. 採用する案（A / B / C）を決める  
2. 必要なら色や `{K+}` の字形を微調整  
3. `1024×1024` を元に `AppIcon.appiconset` を Xcode に登録（DMG ビルド前）

※ 生成画像は AI ラフです。ストア・配布用には採用案をベースに最終調整することを推奨します。
